Getting Started

Go back to the home tab, and click DOWNLOAD. Then download the version that works on you operating system. Open the file. You might need to tell your computer that it isn't mallwear. Now you are ready to use Sampi!

Codeing in Sampi

This is a program that should print "Hello, World!" In the lower box. 

say("Hello, World!)

This creates a variable. 


set x to 1
say(x)

A variable is like a box that stores a value.Right now, There is a box called x with the value 1 in it. You can change varables 


set x to 1
say(x)
set x to x + 1
say(x)

When naming a vaerable in Sampi, There are some rules. It can only have lower case letters, upper case letters, numbers, and (_). It cannot be one of Sampi's keywords. Keywords are just special words that do things. When naming a variable in Sampi, we ask you to use snake_case. That is when you use underscores instead of spaces, like player_x.
