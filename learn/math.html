Math in Sampi is strange. ~3 gives -3. You can't simply use -3. The biggest change is the loss of the order of operations. Normally, 2 + 3 * 4 will return 14 (2 + (3 * 4)), but in Sampi, it just goes left to right, so 2 + 3 * 4 is 20 ((2 + 3) * 4). This is very important when chaining conditions. Condition chaining is when left to right evaluation can be annoying. If you type: 


say(1 = 1 and 2 = 2)

You will get an error! But why? It is because instead of doing it like this: (1 = 1) and (2 = 2), it evaluates it this way: ((1 = 1) and 2) = 2. It tries to see if 1 = 1 and 2, which is invalid. The fix is to run: 


say(1 = 1 and (2 = 2))

Now it evaluates the code: (1 = 1) and (2 = 2), which is what we want! When chaining comparisons, always use parentheses.
